# solve — восстановление функции распределения частиц по размерам из лидарных данных

Инверсия лидарных коэффициентов в распределение частиц по размерам `n(r) = dN/dr`
методом разложения по базисным B-сплайнам с регуляризацией по кривизне
и усреднением по ансамблю окон `[r0, r1]`.

## Постановка задачи

Измерены (набор может быть любым, но в задании — 5 коэффициентов):

| Тип | Длины волн, нм |
|-----|---------------|
| коэффициент обратного рассеяния β | 355*, 532, 1064 |
| коэффициент ослабления α | 355, 532 |

\* в исходном задании указано «533 нм» — здесь трактуется как опечатка
стандартного трёхволнового лидара 355 нм; набор длин волн полностью
определяется входными данными и нигде не зашит в код.

Искомая функция распределения ищется в виде разложения

```
F(r) = Σᵢ Cᵢ Bᵢ(r),   r ∈ [r0, r1],
```

где `Bᵢ` — базисные B-сплайны степени `k ∈ {1, 2, 3, 4}` на логарифмически
эквидистантной сетке узлов. Число базисных функций по умолчанию равно числу
измерений M (в задании M = 5) и настраивается флагом `--n-basis N`. Восстанав-
ливается **объёмное распределение `F(r) = dV/dln r`** (объём частиц в кубометре
воздуха на логарифмический интервал радиуса, мкм³/м³); числовое распределение
получается из него как `n(r) = dN/dr = F(r)·3/(4π r⁴)` (r в мкм).

**Граничные условия.** Из базиса исключаются первая и последняя функции
(B₀ и B_{M-1}) — в зажатом (clamped) базисе только они отличны от нуля на
концах интервала. Поэтому каждое элементарное решение (каждая базисная
функция, а значит и любое разложение по базису) обращается в ноль на
границах: `F(r0) = F(r1) = 0`. В разложении остаётся N−2 функции
(при N = 5 — три), где N — число базисных функций (`--n-basis`).
Отключить условие можно флагом `--no-zero-boundary`.

Прямая задача — интегральное уравнение

```
gⱼ = ∫_{r0}^{r1} Kⱼ(r)·q(r)·Σᵢ Cᵢ Bᵢ(r) dr = (A C)ⱼ,
   Aⱼᵢ = ∫ Kⱼ(r)·q(r)·Bᵢ(r) dr,    q(r) = 3/(4πr⁴),
```

с ядрами (Mie, через `miepython`):

```
ослабление:       Kⱼ(r) = π r² q_ext(r, λⱼ, m)
обратное рассеяние Kⱼ(r) = (r²/4) q_back(r, λⱼ, m)
```

Здесь `q_back` в `miepython` определён через амплитуду обратного рассеяния
`q_back = |Σ (2n+1)(-1)ⁿ (aₙ - bₙ)|² / x²`, откуда дифференциальное сечение
обратного рассеяния на стерадиан `C_back = q_back·r²/4` (проверено по
рэлеевскому пределу).

**Единицы входных данных (согласованы):** β — 1/(м·ср), α — 1/м.
Ядра возвращаются в физических единицах (r в мкм переводится в метры):
`K_ext` — м², `K_back` — м²/ср.  Восстановленное распределение F(r) = dV/dln r
получается в мкм³/м³; из него дополнительно выводятся числовая концентрация
N (м⁻³), объёмная концентрация C_v (мкм³/м³), средний объём частиц ⟨V⟩
(мкм³), эффективный радиус r_eff (мкм) и параметры логнормальных мод —
см. раздел «Выходные данные».

## Метод

1. **Базис.** Для каждого окна `[r0, r1]` строится зажатый B-сплайновый базис
   степени `k` из M функций; внутренние узлы — логарифмически равномерно.
   Крайние функции (B₀ и B_{M-1}) исключаются: каждая базисная функция
   равна нулю на границах, т.е. n(r0) = n(r1) = 0 (флаг
   `--no-zero-boundary` отключает).
   При M = 5 для степени 4 внутренних узлов не остаётся: базис вырождается
   в полиномы Бернштейна степени 4 на весь интервал (корректный предельный
   случай, число функций по-прежнему равно M).
   Квадратуры Гаусса–Лежандра дробятся по узлам базиса и логарифмическим
   подсегментам, чтобы разрешить осцилляции ядер Mie.

2. **Матрица A.** Ядра Kⱼ(r) считаются через `miepython` один раз на плотной
   таблице по r (шаг по параметру размера x ≈ `--dx-max`) и интерполируются
   кубическими сплайнами в логах — это ускоряет перебор окон на порядки.

3. **МНК с регуляризацией по кривизне** (вторая разность коэффициентов):

   ```
   min ||W (A C - g1)||² + γ² ||L C||²,    L — матрица вторых разностей,
   ```

   веса `W = 1/g1` по умолчанию (относительная невязка, согласована с Err).
   При `--nonneg` накладывается `C ≥ 0` (тогда и `F(r) ≥ 0`).

4. **Параметр регуляризации** `γ`:
   - `--gamma-select fixed` (по умолчанию): `γ = γ_rel · ||A||₂`,
     `γ_rel = --gamma-rel 0.1`; одинаковая нормировка для всех окон;
   - `--gamma-select cv`: leave-one-out кросс-валидация по относительной
     невязке (автовыбор γ);
   - `--gamma-select err`: минимум невязки Err (как в исходном описании;
     при M измерений = M неизвестных вырождается в точную интерполяцию).

5. **Невязка** (критерий качества окна):

   ```
   Err = Σᵢ |gᵢ - g1ᵢ| / g1ᵢ
   ```

6. **Ансамбль.** Перебираются окна (r0, r1), степени сплайнов **и сетка
   показателя преломления m** (декартово произведение `--m-reals` ×
   `--m-imags`). Для каждого m строится своя таблица ядер. Берутся G
   решений с наименьшей невязкой (`--best G`). По каждому
   восстанавливается `F(r)`; итоговая функция — среднее по этим G
   решениям с нормировкой по покрытию: в точке r усредняются только
   решения, чьё окно содержит r (точки вне всех окон помечаются NaN).
   **Итоговый показатель преломления — среднее по тем же G лучшим
   решениям** значений m (среднее комплексных чисел).

7. **Сглаживание среднего.** Поточечное среднее решений изломается на
   границах окон (в точке r меняется набор покрывающих решений). Эта
   ступенчатая зависимость сглаживается кубическим сглаживающим сплайном
   (`scipy.interpolate.make_smoothing_spline`) в нормированных координатах:
   аргумент — логарифм радиуса, приведённый к [0,1], значения — F/|F|max,
   поэтому относительный параметр `--smooth-lam` (по умолчанию 1e-4)
   безразмерен и переносится между наборами данных. Веса точек —
   кратность покрытия, крайние точки покрытия притягиваются к сырым
   значениям (без артефактов на границах). Отключить сглаживание —
   `--no-smooth`; сырое (несглаженное) среднее доступно в JSON
   (`n_avg_raw`) и на графике пунктиром.

8. **Анализ мод.** По усреднённому объёмному распределению F(r) оцениваются
   параметры логнормальных мод (в dV/dln r):
   - **fine** — диапазон `r ∈ [r_cov_min, r_split]` (по умолчанию
     `r_split = 0.5` мкм, флаг `--r-split`): `Vf, rm_f, σf`;
   - **coarse** — `r ∈ [r_split, r_cov_max]`: `Vc, rm_c, σc`;
   - **общая оценка** — одна логнормаль по всему покрытому диапазону:
     `V, rm, σ`.
   Значения V — интегралы F по соответствующим диапазонам (мкм³/м³);
   rm, σ — из взвешенного МНК-фита логнормали в координатах (ln r, ln F)
   (веса — кратность покрытия, точки с F ≤ 0 исключены). Если фит
   вырождается (например, для бимодального суммарного распределения
   парабола в ln-координатах получается выпуклой — одной логнормалью
   форму не описать), rm, σ оцениваются по объёмным моментам
   (rm = exp⟨ln r⟩_V, σ = exp(СКО ln r)_V) — оценка выводится всегда,
   способ помечается в таблице и в JSON (`method`: `fit` или `moments`).

Для реальных данных без явных `--m-reals/--m-imags` сетка строится
автоматически вокруг m из файла. Для демо по умолчанию используется сетка
Re = 1.40/1.45/1.50 × Im = −0.01/−0.005/0.

## Установка и запуск

```bash
uv sync                                   # создать окружение (numpy, scipy, matplotlib, miepython)
uv run python -m solve                    # демонстрация на синтетических данных + график
uv run python -m solve --data data.json   # по реальным измерениям
# или (то же самое):
uv run solve
```

Тесты:

```bash
uv run python tests/test_smoke.py
uv run pytest tests/ -q                   # если установлен pytest
```

## Формат входных данных

```json
{
  "m": {"real": 1.45, "imag": -0.005},
  "backscatter": {
    "wavelengths_nm": [355, 532, 1064],
    "coefficients": [1.24e-5, 1.33e-5, 8.75e-6]
  },
  "extinction": {
    "wavelengths_nm": [355, 532],
    "coefficients": [3.78e-4, 4.10e-4]
  }
}
```

**Единицы коэффициентов согласованы:** β — 1/(м·ср), α — 1/м (см. пример).
Все коэффициенты должны быть положительными. Готовый пример —
`examples/input_example.json` (реалистичные значения: β ~ 10⁻⁵ 1/(м·ср),
α ~ 10⁻⁴ 1/м). Поле `units` — справочное, значения коэффициентов не
конвертируются.

`Im(m) ≤ 0` — поглощающая среда (конвенция miepython).

## Выходные данные

- на экран — таблица лучших вариантов (ранг, m, k, r0, r1, γ, Err),
  средний показатель преломления ⟨m⟩, таблица `F = dV/dln r` в ключевых
  точках, согласие по каналам `g` vs `g1`, **параметры мод**;
- **интегральные характеристики** восстановленного распределения
  (по покрытой лучшими решениями области, F ≥ 0 по физ. смыслу):

  | Величина | Формула | Единицы |
  |----------|---------|---------|
  | объёмная концентрация C_v | ∫ F dln r | мкм³/м³ |
  | числовая концентрация N | ∫ F·3/(4πr⁴) dr | м⁻³ |
  | средний объём частиц ⟨V⟩ | C_v / N | мкм³ |
  | эффективный радиус r_eff | ∫r³n dr / ∫r²n dr | мкм |

  (1 мкм³ = 10⁻¹⁸ м³.) Дополнительно выводятся покрытый диапазон
  радиусов и доля покрытия сетки.
- **параметры логнормальных мод** (dV/dln r): для каждой моды —
  V (мкм³/м³), rm (мкм), σ. fine: `[r_cov_min, r_split]`; coarse:
  `[r_split, r_cov_max]`; общая оценка — по всему покрытому диапазону;
- `result.png` — два панно: log-log график `dV/dln r` (лучшие решения,
  сглаженное среднее; при демо — истинное; сырое среднее пунктиром для
  сравнения) и сравнение `g1` с расчётными `g`; на первом панно указано
  ⟨m⟩;
- `--json` — полные результаты: `m_avg`, `moments`, `modes`, сетка `r`,
  `n_avg` (сглаженное), `n_avg_raw` (несглаженное), решения (m, k, r0,
  r1, γ, Err, коэффициенты C), `g_fit` по каналам.

## Ограничения

С 5 измерениями и 5 базисными функциями восстанавливается только гладкая
огибающая распределения: узкие моды (ln σ ≲ 0.4–0.5) «размазываются».
Амплитуда в центрах мод систематически занижается (эффект сглаживания),
что видно на демо-задаче. При необходимости — увеличивайте число каналов
в данных или меняйте сетку окон `--r0-*`/`--r1-*` под ожидаемый диапазон
размеров.

Показатель преломления восстанавливается с точностью до шага заданной
сетки `--m-reals`×`--m-imags`; если оптимальное m попадает на границу
сетки, расширьте её. Время расчёта растёт пропорционально числу значений
m в сетке (для каждого m строится своя таблица ядер).

Интегральные характеристики считаются по покрытой области; из-за
сглаживания N и C_v, как правило, занижаются (амплитуда F(r) занижается).
Граничные условия `F(r0)=F(r1)=0` (по умолчанию) убирают фиктивный хвост
распределения на краях окон, из-за которого ⟨V⟩ и r_eff завышались, —
с ними оценки ⟨V⟩ и r_eff заметно точнее (см. демо). Цена ограничения —
на одно окно приходится N−2 (при N = 5 — три) коэффициентов вместо N,
невязка Err может слегка возрасти. При N−2 > числу каналов система
становится недоопределённой: решение опирается на регуляризацию
(выдаётся предупреждение). Для более точных величин используйте
`--nonneg` и более широкую сетку окон.

Параметры мод (rm, σ) оцениваются по сглаженному среднему: из-за
ограниченного разрешения (5 измерений) моды «размазываются» — σ, как
правило, завышается, rm смещается к центру масс распределения, а Vf и V
восстанавливаются точнее (см. демо). Это фундаментальное ограничение
постановки, а не ошибка алгоритма.
